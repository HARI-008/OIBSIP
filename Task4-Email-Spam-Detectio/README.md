# Email Spam Detection

## Objective

The objective of this project is to classify messages as spam or ham using machine learning and natural language processing.

## Dataset

SMS Spam Collection Dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Data Preprocessing

The messages were cleaned by:

- Converting text to lowercase
- Removing URLs
- Removing email addresses
- Removing numbers
- Removing special characters
- Removing unnecessary spaces

## Feature Extraction

TF-IDF Vectorization was used to convert text into numerical features.

## Machine Learning Models

1. Multinomial Naive Bayes
2. Logistic Regression

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Conclusion

The models were compared using multiple classification metrics and the better-performing model was selected for spam detection.
