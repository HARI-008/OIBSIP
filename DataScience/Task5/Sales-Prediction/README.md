# Sales Prediction

## Objective

The objective of this project is to predict sales based on advertising expenditure.

## Dataset

Advertising dataset containing:

- TV
- Radio
- Newspaper
- Sales

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Exploratory Data Analysis

The project includes:

- TV vs Sales analysis
- Radio vs Sales analysis
- Newspaper vs Sales analysis
- Correlation matrix
- Correlation heatmap

## Machine Learning Models

1. Linear Regression
2. Random Forest Regressor

## Evaluation Metrics

- MAE
- RMSE
- R² Score

## Additional Analysis

Residual analysis and feature importance were performed to understand model performance and the impact of advertising channels.

## Conclusion

The models were compared and the better-performing model was selected for sales prediction.
